# Database Schema Examples

Данный репозиторий содержит набор **production-ready SQL-схем баз данных**, предназначенных для реальных проектов: **CRM, SaaS, ERP и административных панелей**.

Цель проекта — продемонстрировать **грамотное проектирование базы данных**, доменное разделение таблиц и **подробную inline-документацию**, оформленную в виде commit-стиля прямо внутри SQL-файлов.

---

## Описание проекта

Каждый SQL-файл представляет собой **отдельный бизнес-домен** и содержит:
- логически сгруппированные поля
- комментарии к каждому блоку данных
- пояснения, зачем поле существует и где используется
- историю изменений в виде commit-логов

Схемы ориентированы на читаемость, масштабируемость и реальное использование в production-среде.
